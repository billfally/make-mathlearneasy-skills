# make-mathlearneasy-skills

> 一个 WorkBuddy 开源技能（Skill）：以**知识卡片**的形式，为全国大学生数学竞赛（非数学类）生成从当前日期到竞赛日的完整备考规划、学习重难点与知识点讲解剖析。

## 项目解决什么问题

备考全国大学生数学竞赛（非数学类）时，考生普遍面临三个痛点：

1. **规划难**——距离考试（每年 11 月第二个周六，如 2026-11-14）时间不同，不知道按什么节奏安排复习；
2. **抓不住重点**——高等数学内容多（极限、微分、积分、级数、线面积分……），不清楚哪些是竞赛高频考点、哪些是重难点和易错点；
3. **资料散**——讲义、课堂笔记、历届真题分散在各处，缺乏把"知识点 ↔ 讲义章节 ↔ 真题训练"串起来的载体。

本技能把备考过程拆解成**每天/每阶段一张知识卡片**：学习目标 + 知识点讲解剖析 + 重难点警示 + 当日任务（对应讲义章节与真题），让 AI 助手一键生成个性化、可执行的备考方案。

## 主要功能

- **自动排期**：获取当前日期并计算距竞赛日的剩余天数，自动匹配三档规划模板：
  - 剩余 > 120 天：四轮复习（基础 → 强化 → 真题 → 冲刺）
  - 剩余 60–120 天：三轮压缩版
  - 剩余 < 60 天：冲刺版（真题 + 错题为主）
- **知识卡片渲染**：每张卡片聚焦一个主题，统一结构（阶段/日期、学习目标、知识点讲解剖析、重难点警示、今日任务），优先以可视化卡片形式呈现，也可输出 Markdown/HTML 报告。
- **内置备考知识库**（`references/`）：
  - `knowledge-points.md` — 17 个章节的知识点剖析（核心内容 / 重难点 / 竞赛高频考法），覆盖函数、极限、连续、导数、Taylor 定理、不等式证明、零点、函数性质、一元积分、解析几何、多元微分、二重/三重积分、曲线曲面积分、级数与常微分方程，并附讲义 PDF 章节映射表；
  - `competition-guide.md` — 初赛题型结构（满分 100 分、150 分钟）、历届真题（第 1–16 届）使用策略、答题时间分配、高频考点热度表；
  - `plan-templates.md` — 三档备考规划模板与卡片排期原则。

## 安装方法

### 方式一：导入分发包（推荐他人使用）

1. 下载本仓库中的 `make-mathlearneasy-skills.zip`；
2. 在 WorkBuddy 中通过技能管理界面导入该 zip 包；
3. 导入后在对话中即可触发使用。

### 方式二：手动安装（源码方式）

将技能目录复制到 WorkBuddy 用户技能目录：

```bash
# Windows (Git Bash)
cp -r make-mathlearneasy-skills ~/.workbuddy/skills/

# 或手动将 make-mathlearneasy-skills/ 文件夹放到：
# C:\Users\<你的用户名>\.workbuddy\skills\
```

目录结构要求：

```
make-mathlearneasy-skills/
├── SKILL.md                      # 技能入口（元数据 + 工作流程）
└── references/
    ├── knowledge-points.md       # 各章节知识点剖析与重难点
    ├── competition-guide.md      # 初赛题型、真题使用与应试策略
    └── plan-templates.md         # 三档备考规划模板
```

重启或刷新 WorkBuddy 后技能生效。

## 使用方法

安装后，在 WorkBuddy 对话中用自然语言触发，例如：

- 「用知识卡片帮我规划数学竞赛复习」
- 「距数学竞赛还有多少天？给我一份备考规划」
- 「给我讲 Taylor 定理的重难点卡片」
- 「数列极限的竞赛高频考法有哪些？」
- 「生成一份从今天到 11 月 14 日的数竞冲刺计划」

触发后，技能会：

1. 计算当前日期到竞赛日的剩余天数，选择规划模板；
2. 按阶段/天生成知识卡片（可视化卡片或 Markdown/HTML 报告）；
3. 卡片内容取自内置知识库，并将任务映射到你的讲义章节与历届真题。

## 输入输出示例

**输入（用户提问）**：

> 今天是 2026 年 10 月 12 日，帮我做一份到数学竞赛的复习规划

**输出（技能行为）**：

```
检测到距 2026-11-14 初赛约 33 天 → 采用「冲刺版」模板：

第 1 周：高频考点公式卡（极限 / 定积分技巧 / Green·Gauss 公式 / 幂级数）
第 2–5 周：每周 2–3 套历届真题（限时 150 分钟）+ 按失分点回补知识卡片
最后 1 周：错题重做 + 公式记忆 + 按考试时间（9:00–11:30）调整状态
```

随后逐阶段渲染知识卡片，例如：

**输入**：

> 给我一张 Taylor 定理的知识卡片

**输出（卡片结构）**：

| 区块 | 内容示例 |
|---|---|
| 卡片头 | 基础轮 · 第 2 章 · Taylor 定理 |
| 学习目标 | 掌握 Taylor 展开求极限与证明中的阶数选择 |
| 知识点剖析 | 五个基本展开（e^x、sin x、cos x、ln(1+x)、(1+x)^α）；Peano / Lagrange 余项 |
| 重难点警示 | 展开到"分母同阶"；等价无穷小相减时多展一阶；和差中不能直接替换等价无穷小 |
| 今日任务 | 讲义 2.3 节例题 + 历届真题中 Taylor 求极限类题 |

## 适用对象

- 备考全国大学生数学竞赛（非数学 A 类）的本科生；
- 需要高等数学知识点卡片式讲解的学习者。
