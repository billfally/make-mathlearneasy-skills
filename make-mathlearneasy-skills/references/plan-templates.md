# 备考规划模板（按剩余天数选档）

目标日：当年 11 月第二个周六（用户已知 2026-11-14）。把下列模板换算成实际日期区间，再逐阶段生成知识卡片。

## 模板 A：标准四轮（剩余 > 120 天）

**第一轮 · 基础夯实（约 45% 时间）**
按章节推进，每章 1–3 天：1.1 函数 → 1.2 数列极限 → 1.3 函数极限 → 1.4 连续性 → 2.1 导数计算 → 2.3 Taylor → 2.4 不等式 → 2.5 零点 → 2.6 函数性质 → 一元积分 → 解析几何 → 多元微分 → 二重积分 → 三重积分 → 曲线曲面积分 → 级数 → ODE。
每天任务 = 读讲义对应节 + 做讲义例题 + 卡片总结。

**第二轮 · 强化突破（约 25%）**
按专题而非章节：极限专题、中值定理专题、积分技巧专题、证明题专题、计算大题专题（重积分/线面积分/级数求和）。配合历届真题按类刷。

**第三轮 · 真题套卷（约 20%）**
每周 2 套限时模拟（150 分钟），次日逐题订正，错题记入错题卡。

**第四轮 · 冲刺回炉（考前 2 周）**
错题重做 + 公式卡片背诵 + 2 套保持手感；考前 2 天不做新题，只看卡片。

## 模板 B：三轮压缩（剩余 60–120 天）

- 基础+强化合并（约 55%）：章节照常推进，但每章只保留核心卡片（定义/定理/一个典型方法）+ 历届真题同类题；
- 真题套卷（约 30%）：每周 2 套；
- 冲刺（最后 2 周）：同模板 A 第四轮。

## 模板 C：冲刺版（剩余 < 60 天）

- 第 1 周：快速过一遍高频考点热度表 ★★★★★ 项的公式卡片；
- 第 2–5 周：每周 2–3 套真题限时做 + 订正，按失分点回补对应知识卡片；
- 最后 1 周：错题重做 + 公式记忆 + 调整作息到上午 9:00–11:30 状态最佳。

## 卡片排期原则

1. 先排"硬骨头"：中值定理、积分技巧、线面积分放在精力最好的时段；
2. 关联章节相邻：Taylor 紧跟导数计算；三重积分紧跟二重积分；Green/Gauss 紧跟曲线积分；
3. 每 7 天留 1 天缓冲/复盘日；
4. 每张卡片注明：阶段名、日期、对应讲义 PDF 章节、配套真题范围。
